# Neovim プラグイン UI のスクリーンショット確認

Neovim プラグインの UI (float window、ハイライト、列幅、折り返し、選択状態) を、**新しい WezTerm ウィンドウ**で起動して**アプリウィンドウの領域だけ**キャプチャし、GitHub などの参照 UI と比較する。

ユーザーが普段使っている WezTerm ウィンドウには入力しない。IME の影響を避けるため、コマンドはクリップボード経由で貼り付ける。デスクトップ全体は撮らない。

UI の見た目を実機で確認するとき、GitHub などの参照 UI とのギャップを確認するとき、変更前後のスクリーンショットを同じ条件で残すときに使う。

## 前提

- macOS (`osascript` / `screencapture` / `pbcopy` / `sips`)
- WezTerm がインストール済み
- System Events のアクセシビリティ権限と、画面収録の権限
- 検証対象の Neovim を**絶対パス**で指定する。github.nvim は 0.10.4 (0.13.0-nightly は `create_spec.lua` の端末チャネル検証が落ちる)
- 実 API は使わない。fixture と fake `gh` で決定的なデータにする
- スクリプトはテキストのクリップボードを保存・復元する。画像などテキスト以外のクリップボードは復元できない

## 手順

### 1. 最小の init.lua を作る

`references/init-template.lua` をコピーし、プラグインのパス・setup・UI を開く関数・キー操作を埋める。

- `-u` で起動するので、ユーザーの設定は読み込まれない
- `rtp` にプラグインを追加し、`termguicolors`、`laststatus`、`colorscheme` を設定する
- UI は起動 150ms 後に開き、選択状態を写したいときは 1200ms 後にキーを送る
- fake `gh` を使うときは、スクリプトの `--path` で PATH を渡すか、init の先頭で `vim.env.PATH` に足す

### 2. fixture を用意する

`references/fake-gh.md` の形で、`gh` を PATH の先頭に置いた偽物に差し替える。GraphQL の応答を fixture から返し、実データ・レート制限・副作用を避ける。

### 3. キャプチャする

スキルのベースディレクトリから:

```bash
scripts/nvim-ui-capture.sh \
  --init /tmp/nvim-ui-capture/init.lua \
  --out /tmp/nvim-ui-capture/board.png \
  --nvim /tmp/nvim-macos-arm64/bin/nvim \
  --path /tmp/nvim-ui-capture/bin \
  --wait 2.5
```

スクリプトは次を行う:

1. 新しい WezTerm ウィンドウを開く (既存のウィンドウは触らない)
2. 画面に合わせてウィンドウを配置・リサイズする
3. クリップボード経由で `nvim -u init.lua` を貼り付けて実行する
4. `--wait` 秒待ち、`screencapture -x -R...` で**アプリウィンドウの領域だけ**を撮る
5. 出力パス・ウィンドウサイズ・画像サイズを表示する

出力の `captured:` のパスを `read_image` で確認する。ウィンドウは開いたままにし、片付けはユーザーに任せる。

### 4. 詳細を確認する

全体を見て、必要ならカードやヘッダを crop する。`sips` は**高さ→幅**の順で、offset は `y x`:

```bash
sips -c 420 640 --cropOffset 60 0 /tmp/nvim-ui-capture/board.png \
  --out /tmp/nvim-ui-capture/card.png
```

参照 UI と次を比較する:

- タイトルが省略されず、必要な行数で折り返されているか
- 列幅がウィンドウに収まり、右側に余白がないか
- float のボーダーが従来どおりか
- 選択列・選択カードの強調が参照 UI と合っているか
- ラベル、アバター、進捗、関連 PR が表示されているか
- 色 (背景・枠線・文字・選択色) が参照 UI と合っているか

### 5. 反復する

UI を直したら、**毎回新しいウィンドウ**でキャプチャする。既存のウィンドウを再利用すると、前の状態やスクロール位置が残る。変更前後を比較するときは、同じウィンドウサイズ・同じ選択状態・同じデータで撮る。

## トラブルシューティング

- **System Events の権限エラー**: システム設定 > プライバシーとセキュリティ > アクセシビリティで、ターミナル / エージェントに権限を与える
- **画面が黒い・空**: 画面収録の権限を確認する
- **New Window が見つからない**: スクリプトは `Cmd+N` にフォールバックする。WezTerm のキーバインドを確認する
- **IME で文字化けする**: コマンドを `keystroke` で打たない。クリップボード経由で貼る (スクリプトが実施)
- **フォントやレイアウトが崩れる**: Terminal.app ではなく WezTerm を使う
- **デスクトップが写る**: ウィンドウを前面に出し、ウィンドウ領域だけを撮る。全画面キャプチャは使わない
- **Neovim のバージョン違いで落ちる**: 検証対象のバージョンを `--nvim` で絶対パス指定する
